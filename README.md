# DubForge AI Demo

A single-page prototype for an **AI Video Dubber** workflow.

## Features
- Upload an input video file.
- Choose source and target language.
- Pick a voice model for dubbing.
- Simulate transcription → translation → TTS pipeline with progress updates.
- Download a JSON job manifest for integration with backend services.

## Run locally
Open `fitness-website.html` in a browser, or serve with:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000/fitness-website.html`.
